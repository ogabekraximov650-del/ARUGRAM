# CLAUDE.md — GIGACRAFT

Noldan yozilgan, tashqi kutubxonasiz voxel o'yin (Rust + OpenGL ES, Android). Tuzilish: `README.md`.

## Ishlash tartibi (foydalanuvchi talabi, QAT'IY)
- Ish davomida oraliq xabar yozilmaydi; tugagach BITTA yakuniy xabar (nima qilindi, nimani qo'lda tekshirish kerak, nima qolgani).
- Foydalanuvchi bilan faqat o'zbek tilida, oddiy tilda. Taxmin qilmasdan, kodni o'qib tasdiqlang.
- Commit xabarlari o'zbek tilida. Faqat `main` branchga push (avval `git fetch origin main`).
- Yig'ish va testlar FAQAT GitHub Actions'da (`.github/workflows/android.yml`). Mahalliy muhitga hech narsa o'rnatilmaydi, sub-agentlar ishlatilmaydi.
- Tashqi kutubxona (crate) qo'shilmaydi: hammasi shu repoda noldan yoziladi.
- Qaytarib bo'lmaydigan amal yoki ikki xil tushunish mumkin bo'lsa — bitta qisqa savol.
